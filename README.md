The scripts in this repository are focused on:
1. Characterizing asthma-related data in the CHAMACOS participants
2. Creating a new variable "current_asthma" that depends on responses to asthma-related questions to indicate if a participant has asthma at each visit
3. Using current asthma data over time (9-18 years old) to estimate different asthma trajectories using latent class analysis and latent class growth models

The resulting current asthma trajectory labels will be used in downstream analyses
